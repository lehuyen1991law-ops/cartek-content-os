# reports/

| Report | Generated by | Updated |
|---|---|---|
| [import-report.md](import-report.md) | `scripts/import_sheet.py` | On every import that changes data |
| [content-board.md](content-board.md) | `scripts/generate_board.py` | After content changes (CI fails if stale) |
| [audit/](audit/) | People or agents | Point-in-time audits of the source and environment |
| [acceptance/](acceptance/) | People or agents | End-to-end acceptance runs |

Per-item QC reports live with the item: `content/<format>/<ID>-<slug>/qc-report.md`.

Generated reports must not be edited by hand. Audit and acceptance reports are dated and never rewritten: add a new file for a new run.
